Breakout

Simple project made in Visual Studio with C++, CMake and OpenGL.
My first OpenGL project. Inspired heavily by learnopengl.com(https://learnopengl.com/In-Practice/2D-Game/Breakout)

Features:
- 20 levels in various difficulty
- 6 types of powerups
- playthrough saving

Controls:
- a / d or left arrow / right arrow too move the paddle
- w / up arrow to launch the ball
- r to reset
- esc to pause or quit if in main menu

Technical details:
- C++ 20
- CMake 3.20
- OpenGL 3.3 core profile
